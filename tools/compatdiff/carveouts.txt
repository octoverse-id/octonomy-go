text Every field of a `*Update` struct here is a pointer, or `Metadata`, tagged `omitempty` -- the
text shape this line's first release published. On `main` each is `Optional`, a generic type with a
text third state, tagged `omitzero`; Go 1.13 has neither type parameters nor that tag option.

text what still sends it as `{}`, emptying the stored object

section carveout default-api-version
title `Config.APIVersion` defaults to `/api/v1`
text `DefaultAPIVersion` is `APIV1` here and `APIV2` on `main`, and `New` selects it when
text `Config.APIVersion` is empty. This line's first release sent every request to `/api/v1`, and
text moving an existing caller's requests to another surface on an in-range upgrade is a break with
text no version to carry it. So `/api/v2`, and the namespace axis with it, is opt-in here: set
text `Config.APIVersion` to `octonomy.APIV2`.
main const DefaultAPIVersion APIVersion = "v2"
compat const DefaultAPIVersion APIVersion = "v1"

section carveout json-depth-guards
title JSON depth guards that only Go 1.13 needs
text Go 1.13's `encoding/json` has no cycle detection when it encodes and no depth limit when it
text decodes: a `Metadata` that contains itself hangs the process, and a response nested deeply
text enough exhausts the stack, which is a fatal runtime error rather than a panic. This line refuses
text both before `encoding/json` sees them -- a request body whose Go values (maps, slices, structs,
text pointers) nest past 10,000 levels, a cycle among them included, and a response nested past
text 10,000 levels ([`jsondepth.go`](jsondepth.go),
text [#91](https://github.com/octoverse-id/octonomy-go/issues/91)). A modern standard library refuses
text both itself, so `main` carries no such guard; on either line each is an error, and what differs
text is the code that refuses it and the message it returns.
text
text One request differs in outcome. A `json.RawMessage` in a request body is the caller's own
text bytes: the guard does not enter it, and Go 1.13's encoder copies it without recursing, so one
text nested past 10,000 levels is sent from this line, where a modern encoder refuses it.
